# EnsalaBR
## projeto ensalamento da faculdade    

**quais pessoa vão usar o projeto:**
- alunos (Consultam rapidamente a sala e o horário do dia pelo celular, evitando ir ao bloco errado. )
- professores(Conhecem a sala com antecedência para saber se é aula teórica ou laboratório.)
- monitores(Verificam horários vagos para agendar seus plantões de dúvidas sem dar conflito.)
- cordenadores(Cadastram o ensalamento, organizam os espaços da faculdade e resolvem trocas de emergência.)
